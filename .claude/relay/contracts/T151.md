## Baglam

`PlanCalculator.PickFastCodec` (`src/VidShrink.Core/PlanCalculator.cs:899-913`) hizli
kipte aday kodeklerini sirayla geziyor:

```csharp
foreach (var candidate in FastHardwareOrder)
{
    var state = availability.KnownState(candidate);
    if (state == EncoderProbeState.Unmeasured)
    {
        probe.NotMeasured = true;
        return candidate;
    }
    if (state == EncoderProbeState.Working) return candidate;
}
```

**Ilk olculmemis adayda duruyor ve donuyor.** Sirada calisan bir kodek olsa bile ona
hic bakmiyor. Somut sonuc: `av1_nvenc` olculmemis ama `hevc_nvenc` calisan bir makinede
plan `av1_nvenc`i seciyor, `CodecNotMeasured` isaretini tasiyor ve T139 tur 2'nin
getirdigi dogrulama onu **donanim yok** diye kapatiyor — oysa makinede calisan donanim
kodlayicisi **var**. Yanlis-negatif.

Bu tur 1 kararinin urunu, T139 tur 2'nin degil. Tur 2 denetcisi borc 6 olarak bildirdi
ve "ayri sozlesme gerekiyor" dedi; bu o sozlesme.

**Ucuz cevap yanlis olabilir.** "Olculmemisi atla, calisani sec" demek adayin hic
olculmemesine yol acar — sira hep calisan eski kodege duser ve yeni donanim yolu
hic denenmez. Karar bu iki riski birlikte tartmali.
