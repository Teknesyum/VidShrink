## Baglam

T152 muhurlendi: `PlanCalculator.EncoderFallbackReason` (`:909`) artik uc **ayri** cumle
uretiyor ve iki farkli durum ayni cumleye dusmuyor:

```
derlemede yok  -> is not part of this ffmpeg build
olculmedi      -> has not been measured on this machine
olculdu+calismiyor -> could not be used on this machine
```

**Ama kullanici bunu goremiyor.** Denetci izledi: arayuz `plan.Reason`i **hic okumuyor**.
`MainWindow.axaml.cs:2311` `plan.ReasonCodes` uzerinden tek anahtar cagiriyor:

```csharp
ReasonCode.EncoderFallback => Say("main.reason.encoder-fallback", note.RequestedCodec, note.FallbackCodec),
```

```
Locales/en/main.json:285  "the {0} encoder could not be used on this machine, so encoding falls back to {1}"
Locales/tr/main.json:285  "{0} kodlayicisi bu makinede kullanilamadi, bu yuzden {1}'e dusuldu"
```

Yani **olculmemis** bir aday icin bile kullanici "bu makinede kullanilamadi" cumlesini
okuyor — olculmemis bir seyin calismadigini iddia eden cumle. T152'nin duzelttigi kusurun
ta kendisi, bir kat yukarida duruyor. `plan.Reason`in tek dis okuyucusu
`tools/surucu-yoklugu/Program.cs:203`.

`AdviceCode.EncoderFallback` (`MainWindow.axaml.cs:2387-2389`,
`main.advice.encoder-fallback` ve `-gpu`) ayni bicimde uc durumu ayirmiyor.

yakalamak icin** yazilmisti. Ayrisma bugun uc durumun **ikisinde var** ama olcunun tek
girdisi (`RecordingAvailability`) tam da ayrismayan ucuncu duruma dusuyor — o yuzden
